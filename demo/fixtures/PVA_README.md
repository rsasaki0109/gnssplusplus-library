# Synthetic PVA scoring witness

`synthetic_pva.csv` and `synthetic_reference.csv` are project-authored snapshots
at GPST week 2200, seconds 1000–1011. They exercise quaternion conventions,
fixed local frame metadata, missing initialization, scene classification and a
deliberate 180 degree error in the last snapshot with unhealthy heading.

The fixed ENU origin is latitude/longitude 0 degrees. Velocities and Euler
headings are explicit synthetic witnesses; these are not IMU/GNSS sensor data,
a physically simulated vehicle, or field accuracy evidence. No PPC data is
bundled. The primary report must retain the last error even though the health
flag is false. Healthy-only errors are a secondary report.

Run `gnss pva-demo --output-dir new-pva-demo` (add `--plot` with matplotlib).
The demo writes a strict JSON score, per-epoch CSV and a hash manifest. Inputs
can be regenerated by the project-authored `fixture()` in `tests/test_pva.py`.
